# Focus Calm Anchor 🌊

A minimalist focus timer + breathing exercise app built for deep work and mental regulation.

## Why I built it
I wanted something clean and calming — no clutter, no noise, just focus.

## Features
- Pomodoro-style timer
- Guided breathing exercises
- Minimal, calming UI
- Persistent checklist
- Glassmorphism dashboard design

## Built with
- HTML
- CSS
- JavaScript

Just click or type the following URL: https://gitwitrenee.github.io/focus-calm-anchor/
